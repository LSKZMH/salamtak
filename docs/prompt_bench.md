# YOLOE prompt bench

Generated by `scripts/bench_prompts.py` with `yoloe-26n-seg.pt`, imgsz 640, on CPU: 184 images (69 pure negatives). Images stay outside the repo (URLs and licences in the bench folder's `sources.csv`).

Image-level metrics. **Ship rule:** at one threshold (swept 0.15–0.6), hit rate ≥ 0.6, FP rate ≤ 0.1 **and** FP site ≤ 0.1, with the threshold above YOLOE's own reporting floor (0.15). *FP rate* counts every image that does not contain the label (negatives and other labels' positives); *FP neg* pure negatives only; *FP site* the plain construction-site photos among them (what the app actually sees). The best threshold per row is the one with the highest hit rate − FP rate among passing thresholds. Labels that pass but feed only rules that cannot be judged yet are held back.

Caveat: small sets (9–29 positives per label), and phrasings were picked on this same set, so treat rates as ±0.1. Weights: YOLOE-26n (the Space's model).
